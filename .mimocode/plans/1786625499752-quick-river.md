# Plan: Auth-aware buttons + privacy route fix

## Problem
1. Кнопки «Начать обучение» и «Зарегистрироваться» ведут на `/login` и `/register` даже для авторизованных пользователей
2. Роут `/privacy` (Политика конфиденциальности) требует авторизации из-за middleware, а самой страницы не существует

## Changes

### 1. `frontend/app/components/mainPage/Main/Main.jsx`
- Импортировать `useUser` из `@/shared/context/UserContext`
- Сделать компонент клиентским (`"use client"`)
- Логика: если `user` авторизован → `href="/lessons"`, иначе → `href="/login"`

### 2. `frontend/app/components/mainPage/Registration/Registration.jsx`
- Импортировать `useUser` из `@/shared/context/UserContext`
- Сделать компонент клиентским (`"use client"`)
- Логика: если `user` авторизован → `href="/lessons"`, иначе → `href="/register"`

### 3. `frontend/middleware.js`
- Добавить `/privacy` в `PUBLIC_PATHS`: `["/", "/login", "/register", "/privacy"]`

### 4. `frontend/app/privacy/page.jsx` (новый файл)
- Создать страницу политики конфиденциальности (заглушка или шаблон)

## Verification
- Открыть главную страницу без авторизации → кнопки ведут на `/login` и `/register`
- Авторизоваться → кнопки ведут на `/lessons`
- Перейти на `/privacy` без авторизации → страница открывается без редиректа
